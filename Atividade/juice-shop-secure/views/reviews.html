🛡️ Mesmo que um payload XSS seja enviado, ele é armazenado como texto puro e escapado na renderização — nunca interpretado como HTML pelo navegador.

🛡️ Defesas Aplicadas Aqui

✅
Escape na Renderização Os dados são escapados no momento de construir o HTML, não na entrada — a abordagem correta para persistência.
✅
Limite de Comprimento Nome: 80 chars, texto: 400 chars — reduz superfície de ataque e previne buffer overflow em strings.
✅
CSP como Camada Extra script-src 'self' bloqueia qualquer script inline, mesmo que o escape seja bypassado.
