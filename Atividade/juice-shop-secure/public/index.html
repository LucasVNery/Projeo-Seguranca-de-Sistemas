Demonstração de Defesas XSS

Esta versão implementa defesas contra os quatro vetores de XSS. Para comparar com o ambiente vulnerável, acesse http://localhost:3000.

🎯 Cenários de Ataque

🔍

XSS Refletido

Barra de busca que reflete a entrada do usuário — com escape de saída aplicado.

GET /search?q=
⭐

XSS Armazenado

Avaliações de produtos persistidas no servidor — com sanitização e escape na renderização.

POST /reviews
🌐

XSS Baseado em DOM

Manipulação do DOM via fragment da URL — usando textContent em vez de innerHTML.

URL #fragment
⌨️

Keylogger via XSS

Captura de teclas por script injetado — bloqueada pelo CSP, que impede a execução do payload.

addEventListener('keydown')

🛡️ Defesas Ativas Nesta Aplicação

✅
Content Security Policy (CSP) Bloqueia scripts inline e de origens externas. Impede execução mesmo que o payload seja injetado.
✅
Escape de Saída (Output Encoding) Todos os dados do usuário são convertidos para entidades HTML antes de renderizar.
✅
Cookie HttpOnly + SameSite JavaScript não consegue ler o cookie de sessão. SameSite previne ataques CSRF.
✅
X-Frame-Options: DENY Impede que a aplicação seja embutida em iframes (proteção contra clickjacking).
✅
X-Content-Type-Options: nosniff Impede que o navegador adivinhe o tipo MIME do conteúdo.
✅
textContent no DOM O JavaScript do cliente usa textContent em vez de innerHTML para inserir dados dinâmicos.
