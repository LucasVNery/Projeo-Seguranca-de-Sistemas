Prototipo XSS

Demonstracao de Cross-Site Scripting inspirada no OWASP Juice Shop

Aviso: esta aplicacao contem vulnerabilidades intencionais. Execute somente em localhost para fins educacionais.

1. XSS Refletido

O input chega via URL (?q=...) e e devolvido na resposta sem tratamento.

Versao Vulneravel Versao Corrigida
Payload de demonstracao 
<script>alert('XSS Refletido: ' + document.cookie)</script>

2. XSS Armazenado

O input fica salvo no servidor e e executado por toda visita posterior.

Versao Vulneravel Versao Corrigida
Payload de demonstracao 
<img src=x onerror="alert('XSS Armazenado!')">

3. XSS baseado em DOM

O input nunca chega ao servidor; o JS lado-cliente o injeta no DOM com innerHTML.

Versao Vulneravel Versao Corrigida
Payload de demonstracao 
http://localhost:3000/dom-vulnerable.html#<img src=x onerror=alert(1)>

Defesas aplicadas nas versoes corrigidas

  • Escape de saida — converte < > & " ' em entidades HTML.
  • Sanitizacao com DOMPurify quando HTML do usuario precisa ser exibido.
  • Content Security Policy bloqueando inline scripts e eval.
  • textContent em vez de innerHTML no lado cliente.
